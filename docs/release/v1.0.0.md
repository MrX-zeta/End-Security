# End Security 1.0.0

Primera versión de producción: la app Android habla con el servidor real `https://api.endsecurity.lat/api/`.

## Qué incluye
- Registro, acceso, 2FA TOTP, bóveda cifrada de conocimiento cero, generador, salud de contraseñas (HIBP con k-anonimato), dispositivos, actividad y cuenta.
- Sincronización con el backend real (variante `prod`, DEC-65/67).
- Pines TLS (BR-26): se fijan los SHA-256 SPKI de la intermedia Let's Encrypt YR1 y, de respaldo, de la raíz ISRG Root YR. No se fija la hoja. Los pines caducan el 2027-12-31: renovarlos antes (instrucciones en `app/src/main/res/xml/network_security_config.xml`).
- APK firmado con la llave de release, minificado con R8.

## Requisitos
Android 9 (API 28) o superior. Conexión a Internet para sincronizar.

## Verificar el APK
```powershell
Get-FileHash EndSecurity-1.0.0.apk -Algorithm SHA256
apksigner verify --print-certs EndSecurity-1.0.0.apk
```
