## Verificar el APK
```powershell
Get-FileHash EndSecurity-1.0.1.apk -Algorithm SHA256
apksigner verify --print-certs EndSecurity-1.0.1.apk
```

## Compilación de capturas (solo evidencias, no se distribuye)
La release siempre lleva `FLAG_SECURE` (`BuildConfig.SIN_FLAG_SECURE` es `false` fijo y `SinFlagSecureTest` lo vigila). Para capturar pantallas, una compilación `debug` que lo apaga:
```powershell
./gradlew assembleProdDebug -PsinFlagSecure=true -PapiBaseUrl=https://api.endsecurity.lat/api/
```
El APK queda en `app/build/outputs/apk/prod/debug/`; cópialo a `releases/capturas/` (fuera de git). No lleva pines TLS (solo https).
